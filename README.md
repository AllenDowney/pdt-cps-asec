# pdt-cps-asec

Metadata for the [Current Population Survey, Annual Social and Economic Supplement (CPS ASEC)](https://www.census.gov/data/datasets/time-series/demo/cps/cps-asec.html), built to the [PublicDataToolkit](https://github.com/AllenDowney/PublicDataToolkit) standard.

**Status:** started from the PublicDataToolkit template; no records yet.

## What the dataset is

The March supplement to the monthly Current Population Survey, conducted by the Census Bureau for the Bureau of Labor Statistics: income, poverty, work experience, health insurance and living arrangements of the US civilian noninstitutional population.

## Terms of use

The terms are at https://www.census.gov/about/policies.html. They haven't been reviewed yet, so nothing built from this repo may ship (STANDARD.md §8). Once a person has decided them, summarize them here; the decision is in [`dataset.yaml`](dataset.yaml).

## How to get the data

The files are listed in [`sources.yaml`](sources.yaml), with where to get each and its checksum.

## How to use the metadata

- `metadata/releases/<release>/variables.jsonl`: one record per variable, with where each fact came from.
- `docs/`: a page per variable, generated by `make views`.
- `agent/`: shards for LLMs; start with `agent/SKILL.md`.

## How to cite

U.S. Census Bureau and U.S. Bureau of Labor Statistics, Current Population Survey, Annual Social and Economic Supplement (CPS ASEC), public-use file, <year>, <https://www.census.gov/data/datasets/time-series/demo/cps/cps-asec.html>, accessed on <date>.

## How to rebuild

With the sources in `data/raw/` and a PublicDataToolkit checkout next to this repo:

```bash
make build
make views
make check
```
